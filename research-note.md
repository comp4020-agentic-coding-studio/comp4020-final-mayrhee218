
First, I realised that we need to find out exactly "What is AI Agent?"
AI agent is distinguished with AI chatbot that we use through internet like chatGPT web or Gemini. As the IBM website(Anna Gutowska, https://www.ibm.com/think/topics/ai-agents), AI agent means a system that autonomously performs tasks by designing workflows with available tools. AI agents can encompass a wide range of functions beyond natural language processing including decision-making, problem-solving, interacting with external environments and performing actions.
So unlike the simple AI chatbot which only gives the answer in written text based on user input, AI agents do more various works and input is also more massive data(user prompt, folders of computer, Sensor/Real time data..).
